---
name: intake
description: Turn a conversation into meeting notes and proposed issue changes, opened as one pull request in the Houston repo. Use when someone shares a meeting transcript, meeting notes, a Slack thread or an email, or says "intake" or "turn this into issues".
---

Run `.houston/bin/houston skill intake` from the root of this repo and follow the file it prints, start to finish. It prints the team's own `skills/intake/SKILL.md` when there is one, otherwise the core skill.
