---
name: set-me-up
description: Set a person up with Houston in this repo, as the team's first person or as a member joining. Use when someone says "set me up", "I cloned a new repo", "show me my schedule again", "change my run time" or "stop my runs".
---

Run `.houston/bin/houston skill set-me-up` from the root of this repo and follow the file it prints, start to finish. It prints the team's own `skills/set-me-up/SKILL.md` when there is one, otherwise the core skill.
