# projects

One folder per project in `houston.yml`. Inside: one folder per cadence, one folder per period (named by its first day), holding `_page.md` (the period's Notes, written by people) and one Update per person (`<user>.md`, written by their runs). Notes from other meetings go in `<project>/meetings/`; ideas from meetings that have no repo yet go one per line in `<project>/ideas.md`.
