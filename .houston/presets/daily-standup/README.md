# Daily standup

Pick this when the team meets (or posts updates) every working day. Each person's run fills in
what they did, what they're doing and what's in their way, so standup starts from facts.

- `cadences/daily.md`: Mon–Fri at 10:00, one page per day.

Change the time to your standup's time; it's read in each person's own timezone. Combine it with
`weekly-sync` or `sprints-with-kpis` by copying their cadence files too.
