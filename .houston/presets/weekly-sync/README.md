# Weekly sync

Pick this when the team meets once a week instead of daily, or when a daily standup would be too
much. Each person's run sums up their week; the meeting decides what's next.

- `cadences/weekly.md`: Mondays at 10:00, one page per week (Monday to Sunday).

Move the day and time to your sync's. Add `daily-standup` too if you also meet daily.
